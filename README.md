Indian Startup Funding Trends Dashboard

A data analytics project exploring funding patterns across Indian startups — analyzed by sector, city, and year — from raw data cleaning to an interactive Power BI dashboard.

📌 Project Overview

This project analyzes a startup funding dataset to uncover trends in how investment flows across different sectors, cities, and time periods in India's startup ecosystem. The goal was to take messy raw data through a complete analytics pipeline: cleaning → exploration → querying → visualization.

Key questions explored:

Which sectors attract the most funding?
Which cities are emerging as startup hubs?
How has funding activity changed year-over-year?
Who are the most active investors?

Project Workflow
Data Cleaning (Python)
Handled missing values, duplicates, and inconsistent formatting
Standardized city and sector names
Converted funding amounts to a consistent numeric format
Exploratory Data Analysis (Python)
Sector-wise funding distribution
City-wise startup concentration
Year-wise funding trends
SQL Analysis
Wrote queries to extract top-funded sectors, cities, and years
Aggregated investor-level insights
Power BI Dashboard
Interactive dashboard with filters for sector, city, and year
Visuals: bar charts, trend lines, and KPI cards
